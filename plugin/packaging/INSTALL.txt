ND2 for macOS (Apple Silicon, macOS 13 or later): installing
===========================================================

1. Quit REAPER.

2. Copy the plugins (replace older copies if asked):
     ND2.vst3       ->  ~/Library/Audio/Plug-Ins/VST3/        (or /Library/Audio/Plug-Ins/VST3/)
     ND2.component  ->  ~/Library/Audio/Plug-Ins/Components/  (or /Library/Audio/Plug-Ins/Components/)
     ND2.app        ->  /Applications/  (the standalone app; optional)
   In Finder: menu Go > Go to Folder..., paste the folder path, press Return.
   Create the VST3 or Components folder if it does not exist.

3. Clear the macOS quarantine flag. In Terminal type the following, ending with a space (no Return yet):

     sudo xattr -r -d com.apple.quarantine

   then drag ND2.vst3 from Finder onto the Terminal window and press Return (password if asked).
   Repeat for ND2.component and ND2.app. No message means it worked.

4. AU only: let macOS re-read its Audio Unit list (paste in Terminal, press Return):

     killall -9 AudioComponentRegistrar

5. Start REAPER. If ND2 is not listed, open Preferences > Plug-ins > VST and click "Re-scan".

The plugins are ad-hoc signed (not notarised by Apple). That is why step 3 is needed.

6. First start: no firmware is included, and none will be provided. ND2 needs the OS update file v3.00 of the
   original drum module, which you download yourself from the original manufacturer.
     - Click "Locate OS update file..." in the red banner and choose the update file as downloaded: the .dmg, the
       updater app inside it, the Windows .zip or .exe, or os.cab. ND2 keeps a copy of the OS part only.
     - Then click "Load factory banks..." and choose the factory bank download (.zip, a folder, or the bank files).
       ND2 stores them into its memory once (a few seconds) and keeps the result for all later instances.
       "Not now" starts with empty memory; right-click the panel, SYSTEM tab, Factory banks for later.

7. Inputs and outputs:
     Main            stereo, as the original hardware's output
     Ch 1 ... Ch 6   stereo, each channel's share of the main output (copies; the main output is unchanged).
                     Used only when the host enables them (REAPER: route them with the plugin's pin connector).
     Trigger In      6 channels = pads 1-6: piezo or other audio from the host, as the PAD INPUT jacks.
     MIDI            in and out, as the original hardware's MIDI ports.

8. Files ND2 uses (in your Documents folder):
     ~/Documents/ND2/os/               the OS (os.cab, copied from the update file you chose)
     ~/Documents/ND2/cache/            the factory memory built from your bank files, the unpacked default skin
     ~/Documents/ND2/skins/<name>/     your own skins: a folder <name> containing <name>.rml (plus its files)
   Right-click the panel for the ND2 window: SYSTEM (OS update file, factory banks, data folder), BANKS, SKIN
   (skins, Reload skin (F5), zoom) and MIDI.
